# ReefLauncher

**ReefLauncher** — лаунчер Minecraft с собственной атмосферой и уникальными возможностями. Он создан для тех, кто хочет не просто запускать игру, а иметь всё необходимое для комфортной игры в одном месте.

### Возможности
- **Версии Minecraft** — установка и запуск разных версий игры.
- **Сборки** — создание собственных игровых сборок и управление ими.
- **Моды** — удобная установка и управление модификациями.
- **Ресурспаки и шейдеры** — настройка внешнего вида игры.
- **Аккаунты** — управление игровыми профилями.
- **Настройки** — гибкая настройка памяти, Java и параметров запуска.
- **Обновления** — удобное обновление лаунчера и игровых компонентов.

### Собственные механики
- **Reef Profile** — персональный игровой профиль со своими настройками.
- **Reef Themes** — оформление лаунчера с возможностью менять атмосферу интерфейса.
- **Quick Switch** — быстрое переключение между игровыми сборками.
- **Reef Backup** — сохранение важных файлов и настроек сборок.

ReefLauncher — это не просто ещё один способ запустить Minecraft. Это собственная экосистема, которая развивается вместе со своими игроками.
